## Description

Edsger Wybe Dijkstra was one of the most prolific computer scientists of all time. 

This is a lecture by given by Dijkstra in which he tackles two programming exercises using the guarded command language (Dijkstra preferred the term program notation over language) and predicate calculus. Here the use of the predicate calculus does not go beyond standard boolean algebra. He doesn't mention the guarded command language explicitly here, only present's Tony Hoare's notation called the "Hoare Triples", which is a way of defining a program statement's semantics in terms of axioms. 

The first problem is from his paper, Why Correctness Must Be A Mathematical Concern, EWD720: https://www.cs.utexas.edu/users/EWD/transcriptions/EWD07xx/EWD720.html

The second problem is from EWD1215, Courtesy Dr. Birgit Schieder:
https://www.cs.utexas.edu/users/EWD/transcriptions/EWD12xx/EWD1215.html

All EWDs (Dijkstra’s papers) can be found here:
