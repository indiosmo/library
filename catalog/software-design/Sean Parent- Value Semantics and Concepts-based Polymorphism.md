## Auto Summary

Sean Parent gave this talk at C++Now! 2012 in Aspen, Colorado, while a Principal Scientist at Adobe working on Photoshop; the demo implements Photoshop's undo/history feature using a type-erased value type. It is the canonical source of the idea later sloganized as "inheritance is the base class of evil," showing how to get runtime polymorphism without inheritance by giving objects value semantics. An abbreviated version was presented at GoingNative 2013, and the material later evolved into his Better Code series (including the "No Inheritance" talk at NDC London 2017).
