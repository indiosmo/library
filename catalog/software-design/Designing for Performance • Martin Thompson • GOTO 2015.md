## Auto Summary

Martin Thompson is a British performance specialist best known as co-founder of LMAX and creator of the LMAX Disruptor, the lock-free ring-buffer pattern that lets a single thread process millions of trades per second. He popularized the term "mechanical sympathy" (borrowed from racing driver Jackie Stewart) for designing software in harmony with the underlying CPU, cache, and memory hardware, and later built the Aeron messaging library and the SBE codec. The talk's emphasis on clean, cohesive models, batch processing, branch prediction, the Java Microbenchmark Harness (JMH), and CPU performance counters reflects this hardware-aware, measurement-driven philosophy he documents on his Mechanical Sympathy blog.
